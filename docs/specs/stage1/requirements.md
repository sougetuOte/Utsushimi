# 段1「そばにいて、話せて、覚えている」── requirements

**何を段1に入れ、何を送るか。**入れる行には、実際に起動して確かめる完了条件を付ける。
設計は `design.md`、タスクは `tasks.md`。振る舞いの元は `docs/behaviors.md`（BH-01〜BH-42）、段の意味は `docs/concept.md` §3。
技術の前提は ADR 0001〜0004（Python 3.14 ＋ PySide6／SQLite とテキストファイル／Anthropic の公式 SDK と `claude-opus-5-5`／画面と核の2スレッド）。

## 読み方

- **段**：「段1」＝このフェーズの設計で入れる。「段2以降」＝送る（理由を書く）。
- **完了条件**：どれも実起動した本体で観察する事実である。自動テストの結果は数えない（`docs/lessons.md` の読み方）。
  キャラの手触り（口調・人格らしさ・話しかけの間）の最終判定は主人がする（`CLAUDE.md` §2）。完了条件はその手前の事実に限る。
- **タスク**：`tasks.md` の番号。
