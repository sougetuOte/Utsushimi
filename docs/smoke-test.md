# 実起動の手順書（smoke test）

**段1の各タスクで足したふるまいを、実起動した本体で1つずつ起こして確かめる手順。**タスクごとに足していき、T8 で全項目を同じ版で通す（`docs/lessons.md` の B-10・B-11、`docs/specs/stage1/design.md` §8）。
自動の試験の結果は数えない。結果（日付・可／不可・観察したこと）は各タスクの報告に書く。ここには手順だけを置く。

## 前提

- 起動は主人の起動方法で行う：スタートメニューの **Utsushimi**（`Utsushimi.lnk`）。開発用のコンソールからは起動しない。
- ログは `data/logs/utsushimi.log`（1行1出来事。各行に時刻・`pid=`・`thread=`）。発言は `data/utsushimi.db` の `utterances`。
  どちらも足されるだけなので、確かめた起動は `pid=` で引く。
- 本アプリのプロセスは `pythonw.exe`（venv の起動器と実体の2つが並ぶことがある。ログの `pid=` は実体）。

## 項目

### S-1 起動（T1。Bug-1）

1. スタートメニューから Utsushimi を開く。
2. 会話の窓が出て、コンソールの窓が出ないことを見る。
3. ログの `start` 行が `console=none` であることを見る。

### S-2 話す（T1。BH-01・Bug-2）

1. 入力欄に打って Enter（または「送信」）。これを3回、返事が来るのを待ってから繰り返す。
2. 3回とも返事が来て、欄に「あなた：…」と「Utsushimi：…」が順に並ぶことを見る。
3. ログに `send id=` と `reply id=` が交互に3組あり、どれも `thread=core` であること、その `pid=` の `ERROR` が0行であることを見る。

### S-3 強制終了でも残る（T1。BH-13）

1. 1往復話し、ログに `reply id=N` が出たら、すぐ `taskkill /F /PID <ログの pid>` で落とす。
2. もう一度 S-1 の方法で起動し、欄にその発言と返事が残っていることを見る。
3. ログの新しい `start` 行が `prev_shutdown=unclean` で、`loaded=` が N 以上であることを見る。

### S-4 トレイと終了（T1。BH-03・Bug-6）

1. 窓の「×」を押す → 窓が消え、トレイにアイコンが残る（ログ `hide via=close`）。Alt+F4 も同じ。
2. トレイのアイコンの右クリック →「表示」→ 窓が戻る（`show via=tray`）。アイコンの左クリックでも出し入れできる。
3. 右クリック →「隠す」→ 窓が消える（`hide via=tray`）。
4. 右クリック →「終了」→ 5秒以内に窓とトレイアイコンが消える。ログに `shutdown begin via=tray call=1` と `shutdown done` が1回ずつ。
5. `tasklist /FI "IMAGENAME eq pythonw.exe"` に本アプリが無いことを見る。
6. 次の起動の `start` 行が `prev_shutdown=clean` であることを見る。

### S-5 窓を動かす（T1。BH-02 の前半）

1. 窓の上の帯（「Utsushimi」の文字のあたり）を押したままドラッグ → 窓がついてくる。
2. タスクバーに本アプリのボタンが出ていないことを見る（入口はトレイだけ）。

## 画面の目視チェックリスト（L-5・B-11）

画面に関わる変更をしたタスクでは、実起動して次を目で見る。

- [ ] 窓の中の部品（帯・「×」・やり取りの欄・入力欄・「送信」）がすべて見えていて、はみ出し・重なりが無い
- [ ] 文字が欠けずに読める（日本語・英数字とも）
- [ ] 入力欄に打てて、「送信」と「×」が押せる
- [ ] やり取りの欄が縦にスクロールでき、入力行は常に見えている
- [ ] 窓がタスクバーに出ていない。トレイにアイコンがある
